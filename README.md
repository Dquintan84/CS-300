# CS-300

What was the problem you were solving in the projects for this course?

The goal was to create a program that would help academic advisors organize and search for computer science courses. The program needed to read course information from a file, display courses in alphanumeric order, and show prerequisites for individual courses.

How did you approach the problem? Consider why data structures are important to understand.

I started by comparing three data structures: vectors, hash tables, and binary search trees. Each had advantages and disadvantages. I chose the binary search tree because it could organize courses in order without needing a separate sorting process. This helped me understand why choosing the right data structure matters when designing a program.

How did you overcome any roadblocks you encountered?

One challenge was getting the program to read and organize information correctly. I worked through the code one section at a time, tested changes, and fixed errors as they came up. Breaking the project into smaller steps made it easier to understand what was happening.

How has your work on this project expanded your approach to designing software and developing programs?

This project taught me to think more about how a program should work before writing the code. Comparing different data structures helped me understand that there can be several ways to solve the same problem, but some approaches are more efficient than others.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I've learned the importance of keeping code organized, using meaningful names, and adding comments that explain what different sections do. I also understand why separating tasks into functions makes a program easier to troubleshoot and update later.
